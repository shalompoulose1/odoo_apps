Developer Guide

1. Inherit the mixin in your Python model

The mixin already bundles mail.thread, so this works even on models with no chatter today — for example sale.order.line, which has no mail.thread of its own in Odoo core.

from odoo import models, fields

class SaleOrderLine(models.Model):
    _name    = 'sale.order.line'
    _inherit = ['sale.order.line', 'tree.comments.mixin']
    # tree.comments.mixin brings mail.thread with it — no extra step
2. Add the field to the list view XML

Place comment_count with widget="comments_button" inside the <list> tag.

<record id="view_order_line_tree" model="ir.ui.view">
  <field name="model">sale.order.line</field>
  <field name="arch" type="xml">
    <list>
      <field name="product_id"/>
      <field name="price_unit"/>
      <field name="comment_count"
             widget="comments_button"
             string="Comments"
             optional="show"/>
    </list>
  </field>
</record>
3. Add this module as a dependency, then upgrade
{
    'name': 'My Module',
    'depends': ['sale', 'tree_comments_widget'],
    'data': ['views/sale_order_line_views.xml'],
}
# from your Odoo root
python odoo-bin -d <your_db> -u my_module --stop-after-init

Mixin API Reference

Item Type Description
comment_count Integer (computed) Number of chatter messages of type comment or email for the record. Not stored in DB.
_compute_comment_count Method Counts mail.message records matching res_id + model.
